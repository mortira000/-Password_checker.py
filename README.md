# Проверка пароля на Python

Учебный проект по реализации независимых проверок надежности пароля с пошаговой фиксацией изменений через Git / GitHub Desktop.

## Описание проекта

Программа проверяет переданный пароль по пяти независимым критериям безопасности и выводит детальный отчет по каждому из них.

### Критерии проверки:
1. **Минимальная длина** — пароль содержит не менее 8 символов (или заданного порога).
2. **Заглавная буква** — наличие хотя бы одного символа в верхнем регистре (`A-Z`, `А-Я`).
3. **Строчная буква** — наличие хотя бы одного символа в нижнем регистре (`a-z`, `а-я`).
4. **Цифра** — наличие хотя бы одной цифры (`0-9`).
5. **Специальный символ** — наличие хотя бы одного спецсимвола из набора: `!@#$%^&*()-_=+.`

---

## Требования

* Python 3.7 или выше.

---

## Запуск проекта

1. Клонируйте репозиторий или скачайте исходный код.
2. Запустите скрипт `password_checker.py`:

```bash
python password_checker.py
```

3. Введите пароль в консоли и просмотрите результаты проверки.

Пример работы программы:
```text
=== Программа проверки надежности пароля ===
Введите пароль для проверки: Abc!2345

--- Результаты проверки пароля ---
[✓] Пройдено: Длина не менее 8 символов
[✓] Пройдено: Хотя бы одна заглавная буква
[✓] Пройдено: Хотя бы одна строчная буква
[✓] Пройдено: Хотя бы одна цифра
[✓] Пройдено: Хотя бы один спецсимвол (!@#$%^&*()-_=+.)
-----------------------------------
Итог: Пароль надежный!
```
